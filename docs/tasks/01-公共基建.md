### 1. 新建 `core/registry.py`

只放契约，不 import 任何业务模块（避免循环依赖）：

```python
"""
命令注册表：模块自己注册命令，router 只负责分发
职责边界：这里不写业务，不 import 任何 core.xxx 业务模块
"""
from dataclasses import dataclass, field
from typing import Callable, Optional

@dataclass
class Request:
    """一条待处理的用户请求"""
    user_id: str
    group_id: str = ""
    is_group: bool = False
    command: str = ""
    args: list[str] = field(default_factory=list)
    content: str = ""

@dataclass
class Media:
    """本地图片：PNG 字节，由入口层直传 QQ"""
    png: bytes
    name: str = "card.png"

@dataclass
class Result:
    """处理结果"""
    ok: bool
    text: str = ""
    image: Optional[str] = None   # 公网 URL（二维码/兜底）
    media: Optional[Media] = None # 本地 PNG（卡片）

Handler = Callable[[Request], Result]

_HANDLERS: dict[str, Handler] = {}

def register(names, func: Handler) -> None:
    """注册命令，names 是不带前缀的命令名，如 ("星铁角色", "星铁练度")"""
    for n in names:
        key = str(n).strip()
        if not key:
            continue
        if key in _HANDLERS:
            raise RuntimeError(f"命令重复注册: {key}")
        _HANDLERS[key] = func

def resolve(command: str) -> Optional[Handler]:
    return _HANDLERS.get((command or "").strip())

def list_commands() -> list[str]:
    return sorted(_HANDLERS.keys())
```

### 2. 改造 `core/router.py`

保留：`parse_command`、`HELP_TEXT`、`COOKIE_HELP_TEXT`、频率限制、帮助分支、以及**已实现的阶段1命令**（扫码/绑定/解绑）。

删除：`星铁角色`/`星铁练度`/`星铁抽卡` 这些「开发中」占位（改成注册表分发），`_handle_stamina` 保留（T7 会接手）。

分发顺序（必须严格遵守）：

```python
def handle(req: Request) -> Result:
    command = (req.command or "").strip()
    args = req.args or []
    if not command:
        command, args = parse_command(req.content)
    if not command:
        return Result(False, "")

    # 1) 限流 → 2) 内置命令（帮助/Cookie帮助）→ 3) 注册表 → 4) 未知
    if req.is_group and req.group_id and not rate_limiter.check_group(req.group_id):
        return Result(False, "本群请求过于频繁，请稍后再试")
    if not rate_limiter.check_user(req.user_id):
        return Result(False, "操作太频繁了，请 1 分钟后再试")

    if command in ("星铁帮助", "星铁help", "星铁"):
        return Result(True, HELP_TEXT)
    if command in ("星铁cookie帮助", "星铁ck帮助", "cookie帮助", "ck帮助"):
        return Result(True, COOKIE_HELP_TEXT)

    handler = registry.resolve(command)
    if handler is not None:
        try:
            return handler(req)
        except Exception as e:
            logger.error(f"命令 {command} 执行异常: {e}")
            return Result(False, f"{command} 出错了，请稍后重试")

    return Result(False, f"未知指令：{command}\n发送 #星铁帮助 查看可用命令")
```

`HELP_TEXT` 的改造要求：**帮助文案不要写死全量命令**，否则每加一个模块都要改 router。改成按注册表拼装：

```python
def _help_text() -> str:
    # 每个模块在 register 时顺带注册一行帮助文案
```

配套做法：`register(names, func, help_line="")` 增加第三个参数，`_help_text()` 按模块分组（用 `group` 参数控制分组标题，如「账号」「练度」「抽卡」）。分组顺序固定：账号 → 练度 → 抽卡 → 其它。

### 3. 改造 `main.py` 的 `_reply`

图片通道能力由 T2 提供，但**入口层的接线归 T1**，先写好占位：

```python
def _reply(m, result) -> None:
    if result.media is not None:
        # 本地 PNG：上传 + 发送走一条富媒体消息（避免图文两条消息，群聊回复额度只有 5 次/5 分钟）
        from core.render.uploader import send_media
        ok = send_media(m.user, m.user if not m.group else m.group,
                        result.media.png, result.media.name, result.text,
                        is_group=bool(m.group))
        if not ok and result.text:
            m.reply(result.text)  # 直传失败退回纯文本，别让用户什么都收不到
        return
    if result.image:
        m.reply_image(result.image)
    if result.text:
        m.reply(result.text)
```

注意：`m.user` 在群聊里是群成员 openid，`m.group` 是群 openid；`send_media` 的 scene 由 `is_group` 决定。T2 负责让 `send_media` 签名与此一致。
