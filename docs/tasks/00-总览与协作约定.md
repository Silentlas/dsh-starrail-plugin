## 三、共享契约（T1 产出，其他人按这个写）

```python
# core/registry.py
@dataclass
class Request:
    user_id: str
    group_id: str = ""
    is_group: bool = False
    command: str = ""
    args: list[str] = field(default_factory=list)
    content: str = ""

@dataclass
class Media:
    """要发的本地图片：PNG 字节，由 main.py 直传 QQ，不经过图床"""
    png: bytes
    name: str = "card.png"

@dataclass
class Result:
    ok: bool
    text: str = ""
    image: Optional[str] = None          # 公网图片 URL（老路径，二维码在用）
    media: Optional[Media] = None        # 本地 PNG（新路径，卡片统一用这个）
```

注册方式（每个模块自己文件末尾调用，不碰 router）：

```python
from ..registry import register

register(("星铁角色", "星铁练度"), handle_character)
```

约定：

- `register` 的键是**不带前缀的命令名**（`星铁角色`），前缀 `#` `/` `！` 由入口层剥离。
- 同一个命令名不允许注册两次，重复注册会在启动时抛异常（早暴露比静默覆盖好）。
- 所有 handler 签名统一 `func(req: Request) -> Result`，**不直接发消息、不 print**。
- 出图统一返回 `Result(media=Media(png=...))`，**不要再往 `image` 里塞本地路径**（那条路径只能放公网 URL）。
- 文案里不要放 Markdown 表格，QQ 不渲染；用缩进对齐。

## 四、共同规范（每个模块都要满足）

1. **stdout 干净**：任何日志走 `core/utils/logger.py`（已强制 stderr + 脱敏）。调试用 `logger.debug`。
2. **不硬编码 URL 和目录**：接口地址进各自模块的 `config.py`（公共米游社地址进 `core/api/config.py`），数据目录一律用 `get_store()` / roost 下发的 dataDir。
3. **不打印凭证**：Cookie、authkey、stoken 一律只打印长度或前 6 位。
4. **一条命令一条消息**：群聊被动回复只有 5 分钟 5 次的额度，图文必须合成一条富媒体，禁止「先发字再发图」。
5. **异常必须兜底**：handler 内部 `try/except` 转成人话，不要让异常冒到 `on_any_message`（会被 ai-chat 抢答）。
6. **缓存优先**：所有外部数据源都要有本地缓存和 TTL，缓存命中不打网络请求。
7. **冒烟必过**：提交前跑

   ```powershell
   Set-Location -LiteralPath "D:\Personal data\星铁机器人"
   & "D:\Program Files\Python312\python.exe" scripts\smoke_test.py
   ```

   必须输出 `结论: 通过`；新增命令要自己补用例进 `scripts/smoke_test.py`（按现有 `case(...)` 格式）。
8. **单测独立**：纯计算逻辑（评分、统计、解析）写成可用假数据跑的脚本放 `scripts/test_<模块>.py`，不要依赖网络。

## 五、提交与验收

- 分支：`feature/<模块>-<简述>`，例如 `feature-character-mihomo`
- commit：`<类型>: <描述>`，类型 `feat/fix/refactor/docs/chore/test/style`
- 每个模块的 PR 描述里必须贴：冒烟测试结论 + 真实 UID（或假数据）跑出的样例输出
- 合入顺序：T1 → T2/T3/T5/T7 → T4 → T6
- 谁改动共享文件（`core/api/config.py`、`core/utils/store.py`）必须在 PR 里单独列一节「共享文件变更」

## 六、明确不做的事（避免有人自行发挥）

- 不做 Playwright / Chromium 渲染（体积与依赖不可控，本期只用 Pillow）
- 不做完整伤害引擎（只在 T4 里做词条量化与面板总评）
- 不做代理池、不做签名轮换
- 不做米游币签到、深渊/虚构叙事、材料计算
- 不引入第三方图床作为主路径（只作兜底）
- 不在群聊接收 Cookie
