## 一、目标

1. 能在插件进程内把数据画成一张 PNG（纯 Pillow，不装浏览器）
2. 能把这张 PNG 发到 QQ（不经图床、不需要公网 URL）
3. 给其他模块一套稳定、可测的接口

## 二、已验证的关键事实（别重复造轮子）

- `POST /api/qq/call`（roost 面板接口，默认 `http://127.0.0.1:8080`）支持：
  - `method=uploadMedia`，`args` 里给 `fileData`（base64）→ 返回 `file_uuid` + `file_info`（实测 200 成功）
  - `method=sendC2C` / `sendGroup`，`msgType: 7`、`content: ' '`、`media: {file_info}` → 发富媒体
- `args` 的位置参数约定：`__target` 是第一个位置参数，`__rest` 是后续位置参数数组，其余键合成一个对象
- 官方 `file_data` 上限 **5MB**，超过要走分片（本期卡片图远小于 5MB，不做分片，超了降级纯文本）
- 群聊被动回复额度 **5 分钟 5 次**，所以图文必须一条消息

## 四、`uploader.py` 契约（其他人只依赖这个）

```python
"""把本地 PNG 直传 QQ 并发出（经 roost 面板的 /api/qq/call），不经图床"""
import base64
import requests
from ..utils.logger import Logger

logger = Logger("Render")

PANEL_API = "http://127.0.0.1:8080"     # roost 面板地址，可被 main.py 注入覆盖
MAX_DIRECT = 5 * 1024 * 1024            # 官方 file_data 上限

def upload_image(openid: str, png: bytes, is_group: bool) -> str | None:
    """上传本地 PNG，返回 file_info；失败返回 None"""
    if len(png) > MAX_DIRECT:
        logger.warn(f"图片 {len(png)} 字节超过直传上限，降级")
        return None
    scene = "groups" if is_group else "users"
    payload = {
        "method": "uploadMedia",
        "args": {
            "__target": "group" if is_group else "c2c",
            "__rest": [openid],
            "fileType": 1,
            "fileData": base64.b64encode(png).decode(),
        },
    }
    try:
        r = requests.post(f"{PANEL_API}/api/qq/call", json=payload, timeout=20)
        data = r.json()
        if not data.get("ok"):
            logger.warn(f"图片上传被拒: {data.get('error')}")
            return None
        return (data.get("result") or {}).get("file_info") or None
    except Exception as e:
        logger.warn(f"图片上传异常: {e}")
        return None

def send_media(openid: str, target: str, png: bytes, name: str,
               text: str = "", is_group: bool = False) -> bool:
    """
    上传并发送一条富媒体消息（图文同一条，避免超额度）
    openid：单聊是用户 openid，群聊是群 openid
    """
```

要点：

- `text` 直接作为 `content`（官方不接受空 content，空时给一个空格）
- 上传失败**不抛异常**，返回 `False`，由入口层降级成纯文本（`main.py` 已这么接）
- 不要把 `file_info` 打到 INFO 日志（它等价于凭证），最多打长度

要求：

- 高度自适应：最终高度 = 已用内容高度 + 底部留白，不要一开始就固定大画布
- 中文字体：`core/render/fonts.py` 按顺序尝试 `msyh.ttc`（Windows）、`/System/Library/Fonts/PingFang.ttc`（macOS）、`NotoSansCJK`（Linux），**都找不到就抛明确异常**，不要用默认位图字体画中文（会全是方块）
- 深色主题为主（QQ 深色模式观感好），配色集中在 `palette.py`，禁止在 cards 里散落 RGB 元组
